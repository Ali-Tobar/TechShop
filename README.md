# TechShop — Frontend Prototype

A static **Interactive UI Prototype** for an electronics-store landing page. It does not include a backend, authentication, checkout, or payment processing. — Electronics E-Commerce Store UI

A modern and responsive e-commerce web interface for an electronic gadgets store, built using semantic HTML5, custom responsive CSS3, and interactive Vanilla JavaScript.

---

## 🔗 Live Demo & Links

- **Live Demo:** [View Live Site](https://ali-tobar.github.io/TechShop/)
- **Repository:** [GitHub Repository](https://github.com/Ali-Tobar/TechShop)

---

## ✨ Features

- **Responsive E-Commerce Layout:** Optimized for mobile, tablet, and desktop viewports using CSS Grid & Flexbox.
- **Product Catalog Showcase:** Structured product cards displaying images, specifications, pricing, and purchase buttons.
- **Interactive UI (JavaScript):** Dynamic DOM updates, cart/item interactions, and event listeners.
- **Clean Structure:** Semantic HTML architecture for enhanced accessibility and SEO.

---

## 🛠️ Built With

- **HTML5:** Semantic layouts and clean document structure.
- **CSS3:** Responsive design, Flexbox, CSS Grid, and custom hover states.
- **Vanilla JavaScript (ES6+):** DOM manipulation, user interactions, and event handling.
